Personal Portfolio Website01 — Introduction
02 / Problem & Objectives

From static résumé
to interactive presence.

A conventional résumé communicates experience, but rarely demonstrates how a developer builds for the web.

The challenge

  • Static profiles offer limited interaction.
  • Project links and professional details can be scattered across platforms.
  • Responsive design and browser behavior are difficult to demonstrate in a document.

Project objectives

  • Centralize profile, skills, education, experience, and projects.
  • Build an intuitive, responsive interface for multiple screen sizes.
  • Add navigation, interactive behavior, and client-side validation.
  • Publish the website through GitHub Pages.
Personal Portfolio Website02 — Why it matters
03 / Technology Stack

Three core technologies.
One cohesive experience.

Each technology has a distinct role in creating a maintainable, responsive client-side website.

HTML5

Defines semantic structure and organizes the portfolio into meaningful sections.

Structure · Content · Accessibility

CSS3

Controls visual styling, typography, layout, spacing, and screen-size adaptation.

Flexbox · Grid · Media queries

JavaScript

Adds behavior such as menu toggling, smooth navigation, DOM interaction, and form validation.

Events · DOM · Validation

Supporting tools: Visual Studio Code for editing · Git/GitHub for version control · GitHub Pages for deployment.
